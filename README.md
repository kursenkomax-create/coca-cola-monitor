# Coca-Cola Monitor — Railway edition

Монітор шукає **Coca-Cola Classic 0,33 л ЖБ** і **Coca-Cola Zero 0,33 л ЖБ** у магазинах та надсилає Telegram-сповіщення, коли пропозиція відповідає фільтрам.

Поточні основні фільтри:

- ціна до **30 грн за банку**;
- товар підтверджено як наявний;
- післяплата / накладений платіж підтверджені;
- орієнтовна кількість закупівлі — **120 шт**;
- пошук нових сторінок + повторна перевірка вже знайдених кандидатів.

## Railway

Ця версія працює як **one-shot job**: `python main.py` робить одну перевірку і завершується. Railway Cron запускає її кожні 12 годин.

Рекомендований cron:

```text
0 */12 * * *
```

Railway трактує cron у UTC.

### Variables

```text
TELEGRAM_BOT_TOKEN=...
TELEGRAM_CHAT_ID=...
MONITOR_DB_PATH=/data/monitor.db
```

### Persistent database

Для збереження історії між запусками підключи Railway Volume до `/data`.

Детальніше: `RAILWAY.md`.

## Локальний тест

Після встановлення залежностей:

```bash
python main.py
```

Виконається одна перевірка і процес завершиться.
